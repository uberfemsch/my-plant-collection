Export saves your whole collection — labels, notes, dates, and photos — as one JSON file. Import restores it in any browser, on any device. That file is also the labeled list that can grow into a training dataset.

Plants and photos are stored only in this browser's storage on this device — clearing browser data clears them, so keep an export somewhere safe (your files, your email, a GitHub repo). This single HTML file is the whole app: host it on GitHub Pages or just open it from your files, and it works the same.
